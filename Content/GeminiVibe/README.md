Цей гайд призначений для повного налаштування системи з нуля. Після виконання всіх 
кроків, за натисканням комбінації клавіш Ctrl + Shift + F6 прямо в Unreal Engine 
буде відкриватися вікно CMD з AI-асистентом Gemini, який бачить весь ваш C++ код 
та структуру Блупрінтів (змінні, функції, типи даних).

--------------------------------------------------------------------------------
КРОК 1: НАЛАШТУВАННЯ API-КЛЮЧА В WINDOWS
--------------------------------------------------------------------------------
Для роботи скрипта потрібен ключ від Google AI Studio. Його необхідно зберегти 
в системі як змінну оточення, щоб скрипт підтягував його автоматично.

1. Натисніть клавішу Win на клавіатурі та почніть писати: "змінні оточення".
2. Виберіть "Редагувати системні змінні оточення" (Edit system environment variables).
3. У вікні, що відкрилося, знизу натисніть кнопку "Змінні оточення..." (Environment Variables...).
4. У верхньому розділі ("Змінні користувача") натисніть кнопку "Створити..." (New...).
5. Заповніть поля:
   - Ім'я змінної: GEMINI_API_KEY
   - Значення змінної: [Ваш довгий секретний ключ з Google AI Studio]
6. Натисніть ОК в усіх вікнах, щоб зберегти зміни.

⚠️ ВАЖЛИВО: Обов'язково перезапустіть Unreal Engine (та Epic Games Launcher, якщо 
він відкритий) після цього кроку, щоб рушій побачив нову змінну оточення.


--------------------------------------------------------------------------------
КРОК 2: ВСТАНОВЛЕННЯ PYTHON НА КОМП'ЮТЕР
--------------------------------------------------------------------------------
Для роботи зовнішнього вікна консолі чату в Windows потрібен встановлений Python.

1. Зайдіть на офіційний сайт https://www.python.org/downloads/ та завантажте 
   останню версію для Windows (наприклад, Python 3.11 або 3.12).
2. Запустіть завантажений інсталятор.
3. 🔴 КРИТИЧНО ВАЖЛИВО: На першому ж екрані інсталятора знизу поставте галочку 
   навпроти "Add python.exe to PATH". Без цього команда "python" не працюватиме в CMD!
4. Натисніть "Install Now" і дочекайтеся завершення інсталяції.


--------------------------------------------------------------------------------
КРОК 3: ВСТАНОВЛЕННЯ БІБЛІОТЕКИ GOOGLE AI
--------------------------------------------------------------------------------
Тепер потрібно встановити пакет для зв'язку нашого Python з серверами Google.

1. Натисніть комбінацію клавіш Win + R на клавіатурі, введіть cmd та натисніть Enter.
2. У чорне вікно консолі вставте таку команду і натисніть Enter:
   
   pip install google-genai

3. Дочекайтеся завершення завантаження (знову з'явиться рядок для введення тексту). 
   Вікно консолі можна закривати.


--------------------------------------------------------------------------------
КРОК 4: АКТИВАЦІЯ PYTHON-ПЛАГІНІВ В UNREAL ENGINE
--------------------------------------------------------------------------------
Увімкнемо підтримку скриптів всередині самого рушія.

1. Відкрий свій проект в Unreal Engine.
2. У верхньому меню перейдіть в Edit -> Plugins.
3. У пошуку введіть слово "Python".
4. Переконайся, що стоять галочки (активовані) навпроти двох плагінів:
   - Python Editor Script Plugin
   - Editor Scripting Utilities
5. Якщо ставили галочки вперше, натисніть "Restart Now" для перезапуску проекту.


--------------------------------------------------------------------------------
КРОК 5: СТВОРЕННЯ ТА НАЛАШТУВАННЯ БЛУПРІНТА-ЛІНКА
--------------------------------------------------------------------------------
Навчимо Unreal Engine викликати наш файл скрипта `viber.py`.

1. В Content Browser перейдіть у папку "Content/GeminiVibe/" (де лежать скрипти).
2. Клікніть правою кнопкою миші на порожньому місці.
3. Перейдіть в розділ Editor Utilities та оберіть Editor Utility Asset 
   (або Asset Action Utility залежно від версії UE).
4. Якщо запитає Parent Class, оберіть AssetActionUtility.
5. Назвіть створений блупрінт: BP_VibeCoderLink
6. Відкрийте його подвійним кліком.
7. Ліворуч у розділі Functions натисніть кнопку "+" (Створити функцію) і 
   назвіть її: StartVibeChat
8. Клацніть по назві цієї функції (StartVibeChat) і на панелі Details 
   праворуч ОБОВ'ЯЗКОВО поставте галочку "Call in Editor".
9. На графі функції витягніть стрілочку з ноди Start Vibe Chat і створіть 
   ноду "Execute Python Command".
10. У полі "Command" цієї ноди вставте такий рядок коду:

import unreal; unreal.PythonScriptLibrary.execute_python_command(unreal.Paths.project_content_dir() + 'GeminiVibe/viber.py')

11. У лівому верхньому куті натисніть Compile, а потім Save. Вікно можна закривати.


--------------------------------------------------------------------------------
КРОК 6: ПРИВ'ЯЗКА ГАРЯЧИХ КЛАВІШ (Ctrl + Shift + F6)
--------------------------------------------------------------------------------
Фінальний крок — призначення гарячих клавіш для швидкого виклику системи.

1. У головному вікні Unreal Engine перейдіть в Edit -> Editor Preferences.
2. У лівому меню оберіть розділ General -> Keyboard Shortcuts.
3. У полі пошуку вгорі введіть назву вашої функції: StartVibeChat
4. У полі введення гарячих клавіш поруч із знайденою командою натисніть 
   на клавіатурі комбінацію: Ctrl + Shift + F6.
5. Закрийте вікно налаштувань.
